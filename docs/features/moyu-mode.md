# 摸鱼模式

摸鱼模式把当前阅读内容压缩成靠近屏幕底部的窄条，支持单行和双行显示。窗口置顶且不接收键盘焦点，便于在其他应用前短暂查看。

## 显示与窗口操作

- 首次进入时窗口默认放在左下角并保持显示，鼠标首次经过窗口附近后才启用离开自动隐藏；自动隐藏后鼠标靠近会重新显示。
- 从托盘或快捷键手动重新显示时会先保持可见，便于找回窗口。
- 窗口位置和尺寸会保存在本机，后续进入时恢复上次几何位置。
- 按住 Alt 并拖动窗口中央可移动；按住 Alt 并拖动边缘或角落可调整尺寸。调整期间显示对比色轮廓，松开 Alt 后移除。

## 阅读与快捷键

- 窄条滚轮逐段翻句；长句超出当前行数时，未显示部分会留给后续翻页继续阅读。
- 上一句和下一句使用阅读器现有翻页快捷键，不另设独立按键。
- F11 默认切换摸鱼模式，F7 默认切换单行/双行；两者都可在设置中修改。
- 右键菜单提供上一句、下一句、行数切换和退出操作。

## 背景适配

- 自动采样窗口周边的主导背景色，并根据采样结果调整摸鱼条底色。
- 复杂背景沿用专注模式的不透明度上限，减少文字和窗口背景互相干扰。
- 窗口移动或隐藏后重新显示时会重新采样。
