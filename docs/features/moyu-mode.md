# 摸鱼模式设计与实施计划

## 目标与假设

摸鱼模式将当前阅读句显示在屏幕底部的一条窄窗中，默认两行，可切为单行。鼠标进入细条周围约 30 像素范围时显示，离开后约 240 毫秒隐藏。窗口无边框、置顶且不接收键盘焦点；鼠标滚轮和仅在模式开启时注册的可配置全局快捷键负责逐句翻页和退出。按住 Alt 拖动可将细条移到 IDE 状态栏附近。退出时恢复进入前的窗口几何、专注状态和阅读位置。

句子按中英文句末符号和段落换行切分；长句只显示当前行数能容纳的部分，并以省略号提示。摸鱼模式不显示书名、章节、页码或阅读器控件。

## 实施范围

- 新增 `ui/moyu_strip.py`：细条绘制、滚轮、右键备用操作、句子区间切分。
- 更新 `ui/window.py`：进出模式、窗口状态保存与恢复、句子导航、全局热键注册、底部定位。
- 更新 `domain/models.py`、`keys.py`、设置界面和中英文翻译：保存并修改热键与默认行数。
- 在专注设置弹出层和系统托盘提供进入入口。

## 依赖、风险与验证

继续使用 PySide6 与现有 Windows `RegisterHotKey` 封装，不引入依赖。模式热键只在摸鱼模式开启时占用，包括细条自动隐藏期间；用户可在设置中改键以避开 IDE 冲突。自动化测试按会话指令不新增、不运行；使用仓库虚拟环境进行 Python 语法编译，并运行 `git diff --check`。真实 Windows 窗口层级、焦点与滚轮行为本次不做 GUI 验证，交付时明确说明。

## 顺序

1. 建立细条控件与句子区间逻辑，完成滚轮和右键操作。
2. 集成主窗口模式状态、位置、恢复行为及模式期间全局热键。
3. 增加配置入口、快捷键编辑、翻译和默认行数。
4. 检查差异、执行允许的静态验证，并在功能分支本地提交。
